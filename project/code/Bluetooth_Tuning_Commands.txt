蓝牙调参小程序配置说明
======================

一、串口配置
------------

- 串口：UART4
- 波特率：115200
- 发送引脚：C16
- 接收引脚：C17
- 每条命令必须用英文方括号 `[` 和 `]` 包起来。

二、滑杆配置
------------

小程序应按照最右侧格式发送数据，其中 `value` 替换为滑杆当前值。

1. 左上轮 PWM：-6000～6000
   `[slider,pwm.ul,value]`

2. 右上轮 PWM：-6000～6000
   `[slider,pwm.ur,value]`

3. 左下轮 PWM：-6000～6000
   `[slider,pwm.dl,value]`

4. 右下轮 PWM：-6000～6000
   `[slider,pwm.dr,value]`

5. 总目标速度：0～150 cm/s
   `[slider,speed,value]`

6. 总目标距离：0～500 cm
   `[slider,distance,value]`

7. yaw 角 PID 比例系数 Kp：0～20
   `[slider,yaw.kp,value]`

8. yaw 角 PID 积分系数 Ki：0～10
   `[slider,yaw.ki,value]`

9. yaw 角 PID 微分系数 Kd：0～50
   `[slider,yaw.kd,value]`

10. yaw 角前馈最小角速度：0～120 deg/s
    `[slider,yaw.ff,value]`

滑杆说明：

- 改变任意一个 PWM 滑杆后，程序立即进入四轮 PWM 直驱模式。
- 未操作的另外三个轮子保持各自上一次的滑杆值。
- 四轮 PWM 直驱模式直接写 PWM 硬件通道，因此会绕过正常
  `motor_pwm()` 中右上轮固定增加 400 的补偿，滑杆值就是实际下发值。
- 总目标速度和总目标距离供下一次前、后、左、右移动使用，建议先设置
  速度和距离，再按方向按钮。
- `yaw.ff` 修改的是 `path_yaw_feedforward_min_degps`，含义是在 yaw 误差
  超出死区时使用的最小角速度前馈，不是直接叠加到电机 PWM 的数值。

三、按钮配置
------------

- 相对当前车头方向前进：`[forward]`
- 相对当前车头方向后退：`[backward]`
- 相对当前车头方向向左平移：`[left]`
- 相对当前车头方向向右平移：`[right]`
- 逆时针旋转 90°：`[turn90]`
- 逆时针旋转 360°：`[turn360]`
- 顺时针旋转 90°：`[turn90r]`
- 顺时针旋转 360°：`[turn360r]`
- 开启/关闭 yaw 角度闭环：`[yawhold]`
- 停止并关闭 yaw 闭环：`[stop]`
- 查询当前调参状态：`[status]`

按钮也兼容 `[button,forward]` 这种带 `button,` 前缀的格式。
为了兼容队友旧程序，前进和后退还可以发送 `[go ahead]`、`[go back]`。

四、yaw 角度闭环按钮说明
------------------------

- 第一次发送 `[yawhold]`：取消当前 PWM 直驱或位移动作，记录按下瞬间的
  IMU yaw，并开始闭环保持该角度。
- 第二次发送 `[yawhold]`：关闭 yaw 闭环并将四轮输出清零。
- `[stop]` 同样会关闭 yaw 闭环。
- `[status]` 返回 `yawhold=1` 表示已开启，`yawhold=0` 表示已关闭。

五、50 ms 遥测输出
------------------

使用 `Bluetooth_Tuning_Main.txt` 中的蓝牙专用主函数时，程序每 50 ms
自动发送一行：

`TSPD 目标速度 ASPD 实际速度 TPOS 目标X 目标Y APOS 实际X 实际Y TYAW 目标角度 AYAW 实际角度`

示例：

`TSPD 20.0 ASPD 18.6 TPOS 0.500 0.000 APOS 0.213 0.006 TYAW 0.00 AYAW -0.35`

字段和单位：

- `TSPD`：当前 S 曲线目标速度，单位 cm/s。
- `ASPD`：根据四轮编码器计算的车体实际合速度，单位 cm/s。
- `TPOS`：当前目标位置 X、Y，单位 m。
- `APOS`：当前实际里程计位置 X、Y，单位 m。
- `TYAW`：目标 yaw，单位 °。
- `AYAW`：IMU 实际 yaw，单位 °。

六、单片机返回内容
------------------

- `OK ...`：命令接收并执行成功。
- `ERR ...`：命令格式错误、名称未知或参数条件不满足。
- `DONE`：本次距离移动或旋转动作完成。
- `STATUS ...`：当前模式、速度、距离、PWM、yaw PID、前馈和丢帧计数。
- `TSPD ... AYAW ...`：每 50 ms 发送一次的运动遥测。

七、建议测试顺序
----------------

1. 第一次测试 PWM 时把车架空，确保四个轮子离地。
2. 先发送 `[stop]`，再把四个 PWM 滑杆全部设为 0。
3. 每次只缓慢增加一个轮子的 PWM，确认轮子和正反方向对应正确。
4. 位移测试先使用较低速度和较短距离，例如：

   `[slider,speed,20]`

   `[slider,distance,20]`

   `[forward]`

5. 360°旋转由四段连续的同方向 90°闭环旋转组成。不能直接使用
   “当前角度+360°”作为单个目标，否则角度归一化后会等于当前角度，
   小车不会真正转一整圈。
